### 1.3 Ключевые архитектурные различия

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│                            АРХИТЕКТУРНЫЕ АРХЕТИПЫ                                │
├─────────────────────────┬─────────────────────────┬──────────────────────────────┤
│ 1. Mihon (Апстрим)      │ 2. TachiyomiSY (Форк)   │ 3. mihon-vue (Веб-клиент)    │
├─────────────────────────┼─────────────────────────┼──────────────────────────────┤
│ • Нативный Android / JVM│ • Нативный Android / JVM│ • Веб / Десктоп (SPA)        │
│ • Jetpack Compose + M3  │ • Jetpack Compose + M3  │ • Vue 3 + Vuetify 4 (MD3)    │
│ • Встроенная БД SQLite  │ • Расширенная БД SQLite │ • Headless REST + GraphQL    │
│ • Локальная ФС / SAF    │ • Локальная ФС + WebDAV │ • Suwayomi-Server + Storage  │
│ • Внутрипроцессные скрап│ • Внутрипроцессные скрап│ • Изолированные скраперы     │
│ • Демоны WorkManager    │ • Демоны WorkManager    │ • Кэш сервера + опрос/поллинг│
└─────────────────────────┴─────────────────────────┴──────────────────────────────┘
```

1. **Локальная SQLite против удаленного headless-сервера**:
   - *Mihon/SY*: Управляет всей моделью данных непосредственно в локальной базе SQLite на устройстве через SQLDelight/Room. Добавление новых таблиц, объединений (`history`, `updatesView`, `merged`) и атомарных транзакций тривиально.
   - *`mihon-vue`*: Работает строго как headless-клиент, взаимодействующий с **Suwayomi-Server** по протоколам REST (`/api/v1`) и GraphQL (`/api/graphql`). В ситуациях, когда Suwayomi-Server не имеет готовых эндпоинтов (например, триггер фонового сканирования библиотеки, независимая таблица истории, привязка категорий к манге в REST v1), `mihon-vue` применяет клиентские расчеты (`releaseSchedule.ts`), пространства имен в `localStorage`, либо честные неблокирующие информационные диалоги.
2. **Расширения и песочница исполнения**:
   - *Mihon/SY*: Устанавливает расширения в виде `.apk` непосредственно в систему Android с динамической загрузкой DEX-байткода.
   - *`mihon-vue`*: Не может исполнять DEX-код внутри браузера. Все расширения работают на стороне Suwayomi-Server; веб-интерфейс служит для их каталогизации и настройки параметров через REST.
3. **Аппаратные возможности Android против браузерной песочницы**:
   - Навигация кнопками громкости, скрытие окна через `FLAG_SECURE`, аппаратная биометрия через `BiometricPrompt` и циклы перерисовки E-Ink экранов опираются на нативный Android SDK. В `mihon-vue` они заменены на клавиатурные сочетания клавиш, Web Share API, размытие через Canvas при потере фокуса вкладки и чистое мерцание через CSS.

### 2.3 Дельта TachiyomiSY и стратегия адаптации во Vue
- **Динамическая группировка (`LibraryGroup`)**: Главное преимущество TachiyomiSY — трансформация библиотеки «на лету» в виртуальные группы: `BY_SOURCE`, `BY_STATUS`, `BY_TRACK_STATUS`, `UNGROUPED`. В `mihon-vue` это **на 100% реализуемо на стороне клиента** без необходимости изменений в бэкенде! Вся база библиотеки уже загружена в Pinia-хранилище `useLibraryStore().libraryByCategory`. Достаточно реализовать вычисляемое свойство (computed getter) в сторе настроек и добавить 4-ю вкладку «Группировка» в панель `LibrarySettingsSheet.vue`.
- **Сортировка по приоритету тегов**: Пользовательский список тегов в порядке убывания приоритета. Легко внедряется в алгоритм `sortLibrary()` в `library.ts` путем проверки совпадений в массиве `manga.genre`.
- **Фильтр контента 18+**: TriState-фильтр в `LibrarySettingsSheet.vue`, сверяющий теги с маркерами взрослого контента (`Hentai`, `Ecchi`, `Adult`, `18+`) и базой ID NSFW-источников.
- **Массовая смена категорий**: Интерфейс `ChangeCategoryDialog.vue` завершен. Для сохранения данных требуется использовать GraphQL-мутацию Suwayomi `updateManga(input: { id, categoryIds })`.

### 4.3 Дельта TachiyomiSY и стратегия адаптации во Vue
- **Вкладка «Лента» (Feed Tab)**: В TachiyomiSY на экране `FeedTab.kt` отображаются горизонтальные карточные карусели для закрепленных источников и сохраненных фильтров. Для веб-клиента это крайне удобный сценарий: можно внедрить 4-ю вкладку в `BrowseView.vue`, выполняя параллельные запросы к `/source/{id}/latest/1` и `/popular/1` и переиспользуя готовый компонент `GlobalSearchCardRow.vue`.
- **Сохраненные поисковые пресеты (Saved Searches)**: Возможность сохранять сложные наборы фильтров каталога. Реализуется через Pinia-стор `useSavedSearchesStore` с сохранением в `localStorage` (`mihon.savedSearches`). В диалог `SourceFilterDialog.vue` добавляется строка чипов сохраненных пресетов.
- **Прямой экран Smart Search**: В `mihon-vue` уже встроен полноценный движок сопоставления названий `BaseSmartSearchEngine`. Достаточно вынести его в отдельный маршрут `/browse/smart-search/:sourceId`, чтобы запускать поиск дубликатов прямо из карточки манги.

### 5.3 Дельта TachiyomiSY и стратегия адаптации во Vue
- **Объединенная манга (`MergedSource`)**: Позволяет комбинировать главы одного тайтла из разных источников (например, основной перевод MangaDex + экстра-главы с сайта переводчиков). В Suwayomi-Server поддержки слияния нет. В `mihon-vue` это может быть решено клиентским стором виртуального объединения (`mergedManga.ts` в Pinia), формирующим единый список глав в памяти браузера.
- **Пользовательские метаданные и обложка (`EditMangaDialog`)**: Легко реализуется на клиенте! Переопределения названий, авторов и ссылок на обложки сохраняются в `localStorage` по ключу `mihon.manga_overrides.<mangaId>` и накладываются поверх данных сервера в `MangaInfoHeader.vue`. Автозаполнение реализуется подтягиванием данных из уже привязанного трекера (AniList/MAL).
- **Превью страниц**: Загрузка всех картинок главы в браузере без предварительного создания уменьшенных копий (thumbnails) на сервере перегружает сетевой канал. Имеет смысл внедрить как опциональную раскрывающуюся панель, лениво подгружающую только первые 6–8 страниц.
- **Рекомендации**: Могут быть добавлены прямыми публичными запросами к API AniList GraphQL или Jikan (MyAnimeList) по названию тайтла без модификации бэкенда Suwayomi. Клик по рекомендации открывает глобальный поиск.

### 6.3 Дельта TachiyomiSY и стратегия адаптации во Vue
- **Двухстраничный альбомный разворот (Double-Page Spread)**: Критически важная функция для десктопных мониторов и планшетов в альбомной ориентации. Одиночные вертикальные страницы оставляют незаполненными более 60% площади экрана. Реализуется в `ReaderView.vue` объединением пар страниц `[page, page+1]` через CSS Grid/Flexbox с поддержкой инверсии порядка для манги и смещения обложки.
- **Автоматический режим вебтуна**: Проверка жанровых тегов тайтла (`webtoon`, `manhwa`, `long strip`) при открытии читалки в `reader.ts`. Если режим серии не был задан пользователем принудительно, читалка автоматически переключается в вертикальную ленту.
- **Кнопка списка глав на панели читалки**: Добавление отдельной иконки списка глав в `ReaderBottomBar.vue` для прямого вызова нижней шторки глав без необходимости закрывать читалку.
- **Плавный автоскролл вебтунов**: Нативная реализация через `window.scrollBy` и `requestAnimationFrame` с ползунком регулировки скорости (пикселей в секунду).
- **Упреждающая буферизация страниц**: Создание скрытых объектов `new Image().src = ...` для страниц `+1`, `+2`, `-1`, что полностью устраняет задержки и спиннеры загрузки при чтении через удаленный сервер Suwayomi.

### 7.3 Дельта TachiyomiSY и стратегия адаптации во Vue
- **Настройки ExHentai (`SettingsEhScreen`)**: В TachiyomiSY встроен огромный экран настроек для cookies и H@H на 1200+ строк. В архитектуре `mihon-vue` жестко прописывать параметры отдельного источника в ядро не требуется: они динамически отдаются через API настроек источника Suwayomi (`SourcePreferencesView.vue`).
- **Сжатие картинок через Data Saver Proxy**: Маршрутизация запросов страниц манги через сжимающие веб-прокси (`wsrv.nl` или локальный Bandwidth Hero). Очень полезно для пользователей на медленном интернете: легко внедряется в `useReaderImage.ts` добавлением префикса к URL картинки.
- **Синхронизация Syncyomi**: В экосистеме Suwayomi центральный сервер уже является единой базой данных для всех клиентов. Поэтому клиентская P2P-синхронизация **избыточна**: любой веб-клиент или мобильное приложение Suwayomi автоматически синхронизированы через общую базу.
- **Скрытие кнопок навигации**: Добавление тумблеров `showNavUpdates` и `showNavHistory` в `SettingsAppearanceView.vue` позволит пользователям настраивать состав нижней панели или бокового рельса навигации.

   - В `ReaderView.vue` создавать скрытые предзагрузчики `new Image()` для страниц `+1`, `+2` и `-1`, чтобы полностью устранить задержки при перелистывании через удаленный сервер Suwayomi.

### 8.2 Уровень 2: Ценные функции TachiyomiSY, реализуемые на клиенте
*Цель: Эксклюзивные возможности TachiyomiSY, не требующие изменений на сервере и работающие на 100% на фронтенде или текущем API Suwayomi.*

1. **Динамическая группировка библиотеки (`LibraryGroup`)**:
   - *Выполнимость*: 100% на клиенте.
   - *Реализация*: Добавить `groupingMode` (`'default' | 'source' | 'status' | 'track' | 'ungrouped'`) в `usePreferencesStore`. Формировать виртуальные вкладки и категории в `LibraryView.vue` группировкой массива манги по имени источника, статусу чтения или статусу в трекере.
2. **Двухстраничный альбомный разворот (Double-Page Spread для десктопа и планшетов)**:
   - *Выполнимость*: 100% на клиенте.
   - *Реализация*: На широких экранах (`ширина > высоты`) объединять соседние вертикальные страницы в пары через CSS Grid в `ReaderView.vue`. Поддержать сдвиг для первой страницы-обложки и инверсию для манги (справа налево).
3. **Автоопределение режима вебтуна по тегам**:
   - *Выполнимость*: 100% на клиенте.
   - *Реализация*: В `reader.ts` проверять наличие ключевых слов (`webtoon`, `manhwa`, `long strip`) в `manga.genre`. При их наличии автоматически переключать читалку в непрерывную ленту, если у тайтла не выставлен принудительный режим.
4. **Сохраненные поиски и быстрые пресеты фильтров**:
   - *Выполнимость*: 100% на клиенте.
   - *Реализация*: Создать `useSavedSearchesStore` с сохранением именованных наборов фильтров в `localStorage`. Отображать чипы пресетов в верхней части `SourceFilterDialog.vue`.
5. **Вкладка «Лента» в разделе «Обзор» (Feed Tab)**:
   - *Выполнимость*: 100% на клиенте через существующие эндпоинты Suwayomi.
   - *Реализация*: Добавить 4-ю вкладку в `BrowseView.vue`. Запрашивать `/source/{id}/latest/1` и `/popular/1` закрепленных источников и выводить горизонтальные карусели манги через `GlobalSearchCardRow.vue`.
6. **Кастомные названия и обложки манги с автозаполнением из трекера**:
   - *Выполнимость*: 100% на клиенте.
   - *Реализация*: Хранилище оверрайдов метаданных в `localStorage` (`mihon.manga_overrides`). Подменять заголовок, автора, описание и URL обложки в карточке манги. Внедрить кнопку копирования данных из привязанного трекера AniList/MAL.
7. **Кнопка вызова списка глав в читалке**:
   - *Выполнимость*: 100% на клиенте.
   - *Реализация*: Добавить кнопку «Список глав» на панель `ReaderBottomBar.vue` для быстрого переключения между главами.
8. **Панель автоскролла вебтунов**:
   - *Выполнимость*: 100% на клиенте.
   - *Реализация*: Встроить выезжающую панель с ползунком скорости плавного скролла (`window.scrollBy`).
9. **Экономайзер трафика (Data Saver Proxy)**:
   - *Выполнимость*: 100% на клиенте.
   - *Реализация*: Опция в настройках для пропуска изображений через сжимающий прокси-сервер (например, `wsrv.nl/?url=...&q=75&output=webp`).
10. **Переключатели видимости вкладок навигации**:
    - *Выполнимость*: 100% на клиенте.
    - *Реализация*: Настройки скрытия кнопок «Обновления» и «История» из нижней панели навигации с переносом в меню «Еще».

### 8.3 Уровень 3: Заблокировано ограничениями бэкенда или нативной ОС
*Цель: Возможности, требующие доработки Suwayomi-Server либо невозможные в среде браузера.*

1. **Серверная мутация переноса и миграции манги**:
   - Заблокировано до появления в Suwayomi-Server эндпоинта транзакционного переноса истории, закладок и категорий (`POST /api/v1/manga/{id}/migrate`).
2. **Слияние источников манги на уровне сервера (`MergedSource`)**:
   - Для полноценного скачивания и единого хранения объединенных тайтлов требуется поддержка составных источников в архитектуре базы данных Suwayomi.
3. **Предварительный просмотр страниц глав (Thumbnails Previews)**:
   - Загрузка десятков полноразмерных изображений без генерации миниатюр на сервере перегружает внешние сайты. Требуется кэширование миниатюр в Suwayomi.
4. **Синхронизация Syncyomi (P2P)**:
   - Не требуется для веб-клиента, так как Suwayomi-Server уже выполняет роль центральной базы данных.
5. **Аппаратные API Android**:
   - Установка APK, аппаратный сканер отпечатков `BiometricPrompt` и системное дерево разрешений SAF физически недоступны в стандартной песочнице веб-браузера.
